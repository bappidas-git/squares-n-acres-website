## (a) Routes → page component → data endpoints

All routes are declared in `src/routes/index.js`; every page is `React.lazy`-loaded and the
public ones are wrapped in `MainLayout` via the local `PublicRoute` helper. Endpoints are the
paths the page reaches **directly**; endpoints reached through shared components
(`MainLayout` → `Footer`/`NewsletterSection`, `PropertyDetails` → `EnquiryForm`/`FinanceGuide`)
are listed in the notes column.
