## 4. Detailed tasks
1. **`http.js`.** `axios.create({ baseURL: BASE_URL, timeout: 20000, headers: { Accept: 'application/json' } })` where `BASE_URL = process.env.REACT_APP_API_URL` (throw the D48 error when missing). Request interceptor: `Authorization: Bearer <storage.getItem('sna_auth_token')>` when present; `Content-Type: application/json` for bodies. Response interceptor → `ApiError` (`src/services/apiError.js`: `status`, `message`, `errors` (field → string[]), `isNetworkError`, `isTimeout`, `isCanceled`, `original`): 422 → `errors` from the envelope; 401 on a request whose URL starts with `/admin/` or `/auth/` (except `/auth/login`) → call the registered `onUnauthorized()` callback (set by `AdminAuthContext` in prompt 12; default: clear the three `sna_auth_*` keys and `window.location.assign('/admin/login')`) — public calls never redirect; network/timeout → `message: 'Unable to reach the server. Please check your connection and try again.'`; canceled requests → `isCanceled: true` (callers ignore). `http.request(endpoint, { pathParams, params, body, signal, responseType, headers })`: replaces `:param` tokens (URL-encoded; **`:slug(*)`-style params keep slashes**: encode segments individually), filters `params` to `endpoint.query` keys (drop `undefined`/`''`/`null`; arrays → csv; booleans → `'true'|'false'`), validates `endpoint.method`, returns `response.data` (the envelope: `{ data, meta }` or `{ data, message }`), `responseType: 'blob'|'text'` returns the raw data. Export `http`, `setAuthToken(token)` (memoised for the interceptor), `onUnauthorized(cb)`, `buildUrl(endpoint, pathParams, params)` (used by `download.js` later). Tests: URL building with path params and csv arrays, 422 mapping, 401 public vs admin behaviour, network error mapping, cancellation.
2. **Services (one-liners).** Each service exports plain functions: e.g. `propertyService.list = (params, opts) => http.request(endpoints.properties.list, { params, ...opts })`, `getBySlug = (slug, opts) => http.request(endpoints.properties.bySlug, { pathParams: { slug }, ...opts })`, `featured`, `similar(id)`, `view(id)`, `suggestions(q)`, admin: `adminList`, `adminGet`, `create`, `update` (PUT), `patch`, `remove`, `duplicate`, `bulk`, `checkSlug`; `leadService.create/adminList/adminGet/patch/remove/claim/addNote/removeNote/bulk/exportUrl()`; `articleService` (list/bySlug/trending/categories/tags/authors/authorBySlug/admin*/previewToken); `seoService` (settings, adminSettings, updateSettings, overview, llmsPreview); `settingsService` (public, admin, update); `masterDataService` (`localities.list/bySlug/admin*`, `cities`, `propertyTypes`, `amenities`, `badges`, `developers.*`, `banks`, `faqs.*`, `testimonials.*`, `team.*`, `partners.*`); `pageService` (bySlug/admin*/previewToken); `mediaService`; `userService`; `dashboardService.get()`; `newsletterService.subscribe/adminList/remove/exportUrl`; `careerService` (jobs list/bySlug/apply/admin*, applications admin*); `redirectService` (list/resolve/admin*/import/exportUrl); `authService` (login/logout/profile/updateProfile/changePassword). No transformation of shapes anywhere. `src/services/index.js` re-exports all.
3. **`useApi(fetcher, deps, { enabled = true, initialData = null, keepPreviousData = false, onSuccess, onError })`** → `{ data, meta, loading, error, refetch, setData }`; creates an `AbortController` per call, aborts on deps change/unmount, ignores `isCanceled` errors, sets `error` (ApiError) otherwise, `loading` true only for the initial load unless `keepPreviousData` is false. **`useApiList(fetcher, { initialParams, syncToUrl = false, paramKeys, defaults, debounceMs = 0 })`** → `{ items, meta, loading, error, params, setParams(patch), setPage, setSort, setFilters, resetFilters, refetch }`; when `syncToUrl` it reads/writes `useSearchParams` for `paramKeys` (csv arrays, numbers, booleans serialised per §5.6; defaults omitted from the URL; `page` reset to 1 when any filter changes); it debounces `q`. Tests with a fake fetcher (resolve/reject/abort; URL sync round-trip using `MemoryRouter`).
4. **Contexts.** `SiteSettingsProvider` loads `settingsService.public()` and `seoService.settings()` once on mount, exposes `{ settings, seoSettings, loading, error, refresh }`, seeds from `sessionStorage['sna_site_settings_cache']` for instant first paint and updates the cache after every successful load; `useSiteSettings()` returns `settings` with safe defaults (`settings?.general?.siteName ?? SITE.name`, helper getters `getContact()`, `getLogoUrl()`, `getWhatsappLink(message)` → `https://wa.me/<digits>?text=`). `MasterDataProvider` loads localities, cities, property types, amenities, badges, developers, banks in parallel (`Promise.allSettled`), exposes `{ localities, cities, propertyTypes, amenities, badges, developers, banks, loading, refresh, byId(collection, id), bySlug(collection, slug) }`, cached in `sessionStorage['sna_master_data_cache']` (TTL 10 min). Both providers are mounted in `App.js` above the router (`HelmetProvider > ThemeProvider > BrowserRouter > ToastProvider > SiteSettingsProvider > MasterDataProvider > AdminAuthProvider > AppRoutes`). `refresh()` is called by admin save flows later.

## 7. Edge cases that must work
- Mock down → public pages show `ErrorState` with retry (no redirect to login); admin pages show the error toast.
- 401 on an admin call → session cleared, redirect to `/admin/login` once (no loop on the login page itself).
- `useApi` unmount during a request → no state update warning (`act` warnings in tests = failure).
- `useApiList` with `syncToUrl` and an invalid `page=abc` → defaults to 1.
- `SiteSettingsContext` cache present but API newer → UI updates after load without flicker.
- `toLegacyProperty` on a rent listing → `priceUnit 'per month'` + `price = rentPerMonth`; on a plot → `configuration []`.
