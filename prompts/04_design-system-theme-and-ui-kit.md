## 1. Context
`src/assets/styles/global.css` defines the HOM tokens (`--color-primary #1B2A4A`, `--color-secondary #C9A86C`, `--color-bg-surface #F8F6F3`, `--font-heading 'Playfair Display'`, `--font-body 'DM Sans'`, `--font-number 'Outfit'`, spacing `--spacing-xs…3xl`, radius, shadows, z-index, `.section-padding`, `.skip-to-main`, slick overrides, reduced-motion block) and `src/theme.js` a MUI theme with the same palette/fonts and component overrides (Button radius 12, Card, TextField, AppBar, Chip, Accordion, IconButton focus `#C9A86C`, Tab). ~1 200 hex literals live in JS/JSX (`sx`, inline styles, data constants such as `adminConstants.js` status/category colours, `property-tabs/constants.js` `TAG_OPTIONS`, `UserManagement.jsx` `ROLES`, `IconPicker.jsx`, `SeoGuidelines.jsx`, `FinanceGuide.jsx`, `ConstructionStatus.jsx`, `PropertyDetails.jsx`, every admin page) and ~290 in CSS modules (`#1B2A4A` hero gradients on 14 public pages, `rgba(201,168,108,·)` ≈ 40 uses, `#fff` ≈ 130, quiz colours `#22c55e/#ef4444`, etc.). Breakpoints are fragmented (MUI `md` 900 in `MainLayout`/`PropertyCard`/`ToastProvider`/`AdminLayout` vs CSS 960/961 in `Header`/`MobileHeader`/`BottomNav`/`PropertyCard`/`PropertyFilters`, 899 in `AdminLayout.module.css`, 600/768/1024 elsewhere) → no header renders between 900 and 960 px. Three scroll-hide implementations exist (Header, MobileHeader, BottomNav) plus `useThrottledScroll` (used only by `BackToTop`). 13 public pages declare an identical local `Section` component using `react-intersection-observer`. `react-slick` is used only by `SimilarProperties.jsx`; `react-countup` only by `BuilderOverview.jsx`; `sweetalert2` only by `PropertyDetails.jsx` (`Swal.fire` success alerts); `react-intersection-observer` by 36 files; `framer-motion` by 51 files. Three toast systems exist (`ToastProvider`, `AdminLayout` Snackbar, `UserManagement` Snackbar). `ErrorBoundary` in `App.js` and `BackToTop.jsx` use inline HOM colours. Footer is dark (`#1B2A4A`) with a temporary white logo container (prompt 02).

## 2. Objective
When this prompt is finished the design system exists and is applied everywhere: `global.css` and `theme.js` hold the SNA tokens (the only two files with hex literals, verified by `check:traces` with an empty allow-list and by `src/theme.test.js`), Manrope/Inter typography is live, `src/components/ui/*` provides the kit of §8.4, `src/hooks/useInView.js`/`useCountUp.js`/`useScrollDirection.js`/`useBreakpoint.js` replace the removed libraries and duplicated logic, every component/page/CSS module is migrated to tokens (no hex/rgba/font literals outside the two token files), the header/mobile header/bottom nav/footer are restyled on the unified 900 px breakpoint (structure and links unchanged except the footer becoming a light surface), `sweetalert2`, `react-slick`, `slick-carousel`, `react-countup`, `react-intersection-observer` are uninstalled, and a single `ToastProvider` serves public and admin. Functionality is unchanged.
