## 7. Edge cases that must work
- Nested slug `buyer-assistance/home-loan` resolves via the catch-all and via `/buyer-assistance/:slug`.
- Draft page without token → 404; with a valid token → renders with a banner; expired token → 404.
- Unknown block type in data → skipped; the admin editor shows it as "Unsupported block" with delete only.
- `stats` block with empty items → nothing rendered (no empty section).
- Quiz with 0 questions → block hidden; checklist progress persists per page.
- `leadForm` block with a `leadSource` not in `LEAD_SOURCES` → admin validation error.
- Slug collision with a reserved prefix (`properties`) → validation error "Reserved path".
