## 4. Detailed tasks
1. **`<Seo>` implementation** per §9.2/§9.3: `useSeoResolved({ type, entity, overrides, variables, breadcrumbs, pagination })` → uses `resolveSeoOutput` + `seoSettings` + `settings` (site name/logo/social) → `{ title, description, canonical, robots, og, twitter, articleMeta, links (prev/next/rss/canonical), verification, jsonLd }`; Helmet renders `<html lang="en-IN">`, `<title>`, metas, links, favicons (`BRAND.local*` with Cloudinary fallback), `theme-color`, `application-name`, `og:*`/`twitter:*`, `article:*`, verification metas (`google-site-verification`, `msvalidate.01`, `p:domain_verify`, `yandex-verification`), `JsonLd` (single script, merged graph), `CustomHtml` (head), and body-end custom HTML via a portal component `CustomBodyEnd` mounted in `MainLayout`. Robots rules: `admin|search|shortlist|notFound|error` and `?preview=` → `noindex,nofollow`; inactive/draft entities → `noindex`; listing rules via `urls.isNoindexListing`; entity `seo.robots` → `index/follow/noarchive/nosnippet/noimageindex/max-snippet/max-image-preview/max-video-preview` directives; global defaults. Canonical: `seoSettings.siteUrl` + path (no trailing slash) or `seo.canonicalUrl`; listing canonical from `listingSeo`. OG image chain per §9.3 with absolute URLs (Cloudinary/picsum already absolute; local `/brand/*` → `siteUrl + path`).
2. **JSON-LD graphs** via `src/seo/schema/buildGraph(type, entity, context)`: home → Organization/RealEstateAgent (from `seoSettings.knowledgeGraph`, `sameAs` from settings social + knowledge graph) + WebSite + SearchAction + (genuine featured testimonials → `Review`/`AggregateRating` attached to the organisation, only when ≥ 1 non-sample); property → `RealEstateListing` `@id <canonical>#listing` (name, description (plain text, ≤ 300), url, datePosted `publishedAt`, dateModified, image[] (up to 10), offers `Offer` (price/priceCurrency INR/availability InStock|SoldOut per `availability`, `priceSpecification` for rent with `unitCode MON`), about `Residence|Apartment|House|SingleFamilyResidence|Place` per property type (apartments/penthouses/studios/builder floors → Apartment; villas/houses/row houses/duplexes → House; plots/land → Place; commercial → Place), `address` PostalAddress (locality/city/region/postalCode/IN; `streetAddress` only when `showExactLocation`), `geo` only when `showExactLocation`, `floorSize` QuantitativeValue (sq ft → `unitCode FTK`), `numberOfRooms`, `amenityFeature[]` (LocationFeatureSpecification), `seller` Organization (developer) when present) + `FAQPage` when faqs + `VideoObject` when videoUrl (name, description, thumbnailUrl (YouTube `hqdefault`), uploadDate = publishedAt, embedUrl); article → `Article`/`BlogPosting` (headline, description, image, author `Person` (name, url), publisher `Organization` (name, logo ImageObject), datePublished, dateModified, mainEntityOfPage, wordCount, articleSection, keywords (tags)) + `FAQPage` (article faqs + FAQ blocks via `onFaqItems`); listing/locality/developer/category/author → `ItemList` (`itemListElement` of the page's cards with position/url/name; ≤ 24); locality → `Place` (name, description, geo, address, containedInPlace City); developer → `Organization` (name, logo, url, foundingDate, description, sameAs website); author → `Person`; page → `WebPage` (name, description, dateModified, breadcrumb ref); every page with breadcrumbs → `BreadcrumbList` `@id <canonical>#breadcrumb`. `entity.seo.schema.type !== 'auto'` overrides the main node type where sensible (property: allowed `RealEstateListing|Product|Place`); `disabledAutoTypes` removes nodes; `schema.custom` parsed/validated and appended.
3. **Breadcrumbs**: `breadcrumbsFor(type, entity, extras)` produces the shared items (Home › Buy › Locality › Title; Home › Localities › Name; Home › Builders › Name; Home › Insights › Category › Title; Home › Buyer Assistance › Page; …) consumed by `ui/Breadcrumbs` (UI) and `<Seo breadcrumbs>` (schema) — pages pass the same array to both.
4. **Wire every page**: Home (`type="home"`), listing routes (`type="listing"`, `variables { count, page }`, `overrides` from `listingSeo`, breadcrumbs, pagination), property (`type="property"`, entity, breadcrumbs, `onFaqItems` from the description `SafeHtml` merged into `faqs`), localities index (`type="page"`-like static: use `type="listing"`? — add `type="localities"` and `type="builders"` index types with fixed titles from `copy.js`), locality (`type="locality"` + ItemList of its visible properties), builders/builder (`developer`), blog index (`type="page"`-static → add `type="blog"`), category/tag/author/article, FAQs page (`type="faqs"` + `FAQPage` graph of all FAQs on the page), CMS pages (`type="page"`; templates `about` → testimonials review graph when genuine), jobs (`type="jobs"`/`job` with `JobPosting` graph — add generator `jobPosting.js`: title, description, datePosted, validThrough, employmentType, hiringOrganization, jobLocation Bengaluru), shortlist (`noindex`), 404 (`type="notFound"`), error boundary page (`type="error"`), admin (`type="admin"`).

6. **Analytics**: `AnalyticsScripts` renders GA4 (`https://www.googletagmanager.com/gtag/js?id=` + config with `send_page_view: false`; page views tracked on route change via `track('page_view')`), GTM (script + noscript iframe in body via portal), Pixel (init + PageView) — each only when its id exists; `web-vitals` reporting is prompt 41.

Both exit non-zero on errors; add `check:links` and `check:jsonld` scripts (not in `check:all`; run in 46/48).

## 7. Edge cases that must work
- Property inactive + admin preview → `noindex` and no `Offer` availability change; unknown slug → 404 page with `noindex`.
- Listing with `page=2` → `rel=prev` to page 1 without `?page=1`; canonical of page 2 includes `page=2` (index-worthy) unless `noindex.paginatedListings`.
- Article scheduled with preview → `noindex`; published → `article:published_time` ISO with timezone.
- Home without a knowledge-graph phone → the property omitted (never empty strings in JSON-LD).
- Custom head HTML with a `<script>` → rendered (admin trust boundary) — documented; manager cannot edit (37).
- Redirect to an external URL → full navigation; loop → stops after 5 hops and logs a `console.warn`.
- `check:jsonld` without Chrome → Node adapter path passes.
